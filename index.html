Select Your Post

Select the government role you want to access.

Farmer / Citizen

Access permitted land information and submit survey-related requests.

Responsibilities:
  • View permitted parcel records
  • View map information
  • Submit survey/resurvey request
  • Upload permitted documents
  • Track application status
  • View approved results
Surveyor

Conduct and prepare land surveys, GIS data and verification evidence.

Responsibilities:
  • Manage assigned surveys
  • Upload old records
  • Capture/import new survey data
  • Manage RTK / Total Station data
  • Upload drone survey data
  • Create GIS boundaries
  • Enter dimensions
  • Run quality checks
  • Compare old vs new data
  • Submit survey for verification
Authorized Officer

Review submitted survey cases and make the configured verification decision.

Responsibilities:
  • Review submitted cases
  • Check old records
  • Check new survey data
  • Review GIS boundaries
  • Check survey quality
  • Review discrepancies
  • Review evidence
  • Approve / reject according to workflow
  • Request resurvey when required
Administrator

Manage platform configuration, projects, monitoring and system controls.

Responsibilities:
  • Manage system configuration
  • Manage villages and projects
  • Manage role permissions
  • Monitor system activity
  • Review audit information
  • Monitor system health
  • Manage platform settings
